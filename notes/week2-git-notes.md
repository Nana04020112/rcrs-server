## 一、仓库基础操作
1. git clone 仓库地址
作用：把远程GitHub项目完整下载到本地，生成本地仓库

2. git add 文件名 / git add .
作用：将工作区修改的文件提交到暂存区，git add . 代表全部文件

3. git commit -m "提交说明文字"
作用：把暂存区内容存入本地仓库，-m 填写本次修改描述

4. git push
作用：将本地仓库的提交同步上传到远程GitHub仓库

5. git pull
作用：拉取远程仓库最新代码，合并到本地

## 二、分支操作
1. git branch
作用：查看本地所有分支；git branch 分支名 用于创建新分支

2. git checkout 分支名
作用：切换到指定分支；git checkout -b 分支名 = 创建并直接切换分支

3. git merge 分支名
作用：将目标分支的代码合并到当前所在分支

## 三、查看/对比信息
1. git status
作用：查看当前文件状态，哪些修改未暂存、哪些在暂存区

2. git log
作用：查看本地所有提交记录、提交ID、作者、时间、备注
